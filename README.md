# 练器助手

这是一个面向健身新手的微信小程序项目，用来沉淀 AI 产品经理方向的第一个可展示、可继续上线的真实产品。

项目目标不是做一个“大而全健身 App”，而是验证一个更小、更稳定的产品假设：

> 对健身新手来说，进入健身房后最大的启动障碍之一是“不知道眼前这台器械叫什么、练哪里、怎么调、怎么避免受伤”。比起一开始依赖不稳定的 AI 视觉识别，第一版先用器械图鉴和外观问答定位，帮助用户稳定找到器械并学习使用方法。

## 如何运行

### 微信小程序版本

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择当前文件夹。
4. AppID 可先选择测试号或游客模式。
5. 编译后查看 `练器助手`。

### H5 历史原型

如需查看早期原型，可直接用浏览器打开 `app/index.html`。

## 微信小程序 V1 核心功能

- 首页：解释产品价值，提供“我看到一台器械”和“器械图鉴”入口
- 找器械：按训练部位和外观特征定位可能器械
- 器械图鉴：支持按部位筛选和关键词搜索
- 器械详情：展示用途、调节方法、动作步骤、常见错误、安全提醒和新手组数
- 收藏：把常用器械保存到本地
