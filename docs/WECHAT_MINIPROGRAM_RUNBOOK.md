# 微信小程序运行与维护说明

## 1. 如何打开项目

1. 安装并打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本仓库根目录：`健身小程序-vibe coding`。
4. AppID：
   - 暂时预览：选择测试号或游客模式。
   - 准备发布：填写你自己的微信小程序 AppID。
5. 点击“编译”，默认进入首页。

## 2. 当前页面

| 页面 | 文件 | 作用 |
| --- | --- | --- |
| 首页 | `miniprogram/pages/home` | 产品说明、入口、收藏列表 |
| 找器械 | `miniprogram/pages/finder` | 通过部位和外观特征定位器械 |
| 图鉴 | `miniprogram/pages/library` | 搜索和筛选全部器械 |
| 详情 | `miniprogram/pages/detail` | 教学、安全提醒、收藏 |

## 3. 如何增加器械

编辑 `miniprogram/data/equipment.js`，按已有格式新增一条数据：

```js
{
  id: "unique-id",
  name: "器械名称",
  aliases: ["别名", "搜索词"],
  bodyParts: ["胸部"],
  features: ["坐着用", "往前推", "有靠背"],
  motion: "一句话说明它练什么。",
  setup: ["怎么调座椅", "怎么选重量"],
  steps: ["动作步骤 1", "动作步骤 2"],
  mistakes: ["常见错误"],
  safety: "安全提醒。",
  beginner: "新手推荐组数。",
  level: "新手友好"
}
```

注意：

- `id` 不能重复。
- `bodyParts` 最好使用已有部位：胸部、背部、腿部、臀部、肩部、手臂、核心。
- `features` 最好使用已有特征，方便找器械页匹配。

## 4. 发布前检查清单

- 在微信开发者工具中确认 4 个页面都能打开。
- 测试“找器械”：选择部位和特征后有结果。
- 测试“图鉴”：搜索“推胸”“下拉”“腿”等关键词有结果。
- 测试“详情”：收藏和取消收藏正常。
- 在真机预览中确认字体、按钮和卡片没有溢出。
- 发布前替换测试 AppID，并补充隐私政策和用户协议。

## 5. 产品边界

当前版本不做自动视觉识别，也不上传照片。器械定位依赖用户选择外观特征，并由用户最终确认。这样可以避免误识别带来的训练安全风险。

## 6. 下一版建议

1. 增加器械图片，提高对照确认效率。
2. 增加“没找到器械”反馈入口，用来收集缺失数据。
3. 增加 AI 问答：用户可追问“膝盖不舒服还能做吗”。
4. 增加训练计划：根据收藏器械生成今日训练。
