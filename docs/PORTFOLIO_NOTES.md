# 作品集与简历表达

## 项目一句话

练器助手是一个面向健身新手的微信小程序，通过器械图鉴和外观问答定位，帮助用户在健身房快速找到眼前器械，并学习如何调节、使用和避免常见错误。

## 面试讲述结构

### 1. 背景

我希望做一个能体现 AI 产品经理能力的从 0 到 1 项目，因此没有从技术炫技开始，而是先选择一个高频、清晰、可闭环的用户场景：健身新手进入健身房后，不知道眼前的器械叫什么、练哪里、怎么调、怎么安全使用。

### 2. 用户问题

健身新手的核心障碍不是缺少健身内容，而是现场认知成本高。用户看到器械时往往不知道关键词，导致无法搜索；即使搜到视频，也不一定能快速理解机器怎么调、动作哪里容易错。

### 3. 产品方案

首版聚焦一个最小闭环：

- 用户选择训练部位和外观特征
- 系统推荐可能器械
- 用户对照确认器械
- 查看调节方法、动作步骤、常见错误和安全提醒
- 收藏常用器械

### 4. MVP 取舍

我刻意没有在首版依赖 AI 视觉识别、二维码、视频库、社交和商业化功能。AI 视觉识别存在误识别风险，二维码在线下公共场景难以稳定维护。第一版先验证“用户能否不用拍照、不用扫码，也能快速定位并学会使用器械”。

### 5. AI 产品思考

首版不把 AI 放在识别主链路，而是先把用户问题稳定解决。后续 AI 可以作为增强能力：

- 根据用户身高、经验和身体状态改写器械说明
- 回答用户对动作和安全风险的追问
- 根据收藏器械生成训练计划
- 在数据足够后评估 AI 视觉识别作为辅助入口

### 6. 可量化指标

如果进入真实用户测试，我会优先观察：

- 找器械流程完成率
- 详情页停留时长
- 收藏率
- 搜索无结果率
- “没找到器械”的反馈比例

## 简历项目描述

练器助手｜健身新手器械指南微信小程序

- 从 0 到 1 设计面向健身新手的器械指南小程序，完成用户痛点分析、MVP 取舍、核心流程和验收标准设计。
- 在评估 AI 视觉识别误识别风险和二维码线下维护成本后，将 V1 主路径调整为“器械图鉴 + 外观问答定位”，提升产品稳定性和可上线性。
- 使用 vibe coding 完成原生微信小程序 V1，实现首页、找器械、图鉴搜索、器械详情和本地收藏闭环。
- 规划后续 AI 能力升级路径，包括个性化说明、动作问答、训练计划生成和视觉识别辅助入口。

## 下一步迭代建议

1. 增加“没找到器械”反馈入口。

4. 接入真实 LLM，让用户追问安全和动作问题。
5. 整理成作品集页面：背景、洞察、方案、原型、指标、复盘。
