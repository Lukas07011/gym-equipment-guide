# 器械图片与视频素材说明

## 当前状态

本版本已经为 8 台常见器械补充了图片和视频字段：

- 图片：使用项目内本地 PNG 示意图，路径在 `miniprogram/assets/equipment/`。
- 视频：详情页已有视频示例模块，但真实视频链接暂未接入。
- 视频脚本：每台器械都在 `miniprogram/data/equipment.js` 中配置了 3 个建议镜头，方便后续拍摄。

## 为什么视频先不直接引用网上链接

公开视频平台的视频通常不适合直接放进微信小程序：

- 可能没有版权授权。
- 小程序视频播放通常需要可访问的视频文件地址。
- 线上小程序还需要配置合法服务器域名。
- YouTube、B 站等页面链接不等于可直接播放的 MP4 地址。
- 健身动作涉及安全风险，最好使用自己审核过的内容。

因此 V1.1 的策略是：

1. 先把视频模块和数据结构做好。
2. 用拍摄脚本明确每台器械需要什么镜头。
3. 等有实拍或授权视频后，把 `video.url` 填上即可显示真实播放器。

## 如何替换器械图片

推荐图片规格：

- 格式：PNG 或 JPG
- 比例：16:9 或接近 720x420
- 内容：清楚展示整台器械，不要过度裁切
- 命名：使用器械 id，例如 `lat-pulldown.png`

替换步骤：

1. 把图片放入 `miniprogram/assets/equipment/`。
2. 在 `miniprogram/data/equipment.js` 中确认对应 `image` 路径。
3. 打开微信开发者工具重新编译。

## 如何接入真实视频

每台器械的数据结构如下：

```js
video: {
  title: "高位下拉新手示范",
  duration: "35-45 秒",
  url: "",
  status: "待接入实拍视频",
  shots: ["镜头 1", "镜头 2", "镜头 3"]
}
```

接入真实视频时：

1. 上传视频到你可控的服务器或腾讯云点播。
2. 确认视频地址可被小程序访问。
3. 在小程序后台配置合法域名。
4. 把 `url` 改成视频地址。
5. 把 `status` 改成 `已接入视频示范`。

## 建议拍摄标准

每条视频控制在 30-60 秒：

1. 展示器械整体和关键调节点。
2. 演示 2-3 次正确动作。
3. 演示 1 个最常见错误。
4. 最后给一句安全提醒。

拍摄时避免拍到其他健身房用户的正脸，避免隐私风险。
